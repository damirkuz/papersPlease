# Министерство дней рождения
## Пограничный контроль

Локальная браузерная игра для командного поздравления. Ведущий управляет проверкой, коллеги обсуждают версии, именинники могут дополнить свои истории. У Саши, Нияза и Марка есть отдельные дела и медали. Все три разрешения попадают в общий реестр с печатью **ОДОБРЕНО / APPROVED**.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm install
npm run dev
```

Откройте [http://127.0.0.1:5173/](http://127.0.0.1:5173/) или адрес из терминала. Выберите «Начать проверку» → «Саша». Клавиша **F** включает полный экран, **M** переключает звук. Звук при запуске выключен.

```sh
npm run build
npm run preview
```

Для показа сборки откройте [http://127.0.0.1:4173/](http://127.0.0.1:4173/). Игра, графика, шрифты и звук работают локально. Прогресс и настройки хранятся до перезагрузки страницы. Участники голосуют голосом или в чате звонка. Ведущий сам решает, когда раскрывать ответ.

## Проверки

```sh
npm run validate:content
npm run typecheck
npx playwright install chromium
npm test
```

Для уже установленного Google Chrome используйте `PLAYWRIGHT_CHANNEL=chrome npm test`. Playwright запускает свой локальный сервер на порту 4178. Чтобы переснять основные сцены, передайте `SHOW_SCREENSHOTS="$PWD/docs/screenshots"` при запуске `npm run test:e2e`.
