# Работа с игрой

- Начинайте с [руководства по контенту](docs/CONTENT_GUIDE.md). Дело одного человека хранится в одном JSON в `src/content/characters/`. Подключайте дело через `src/content/manifest.ts`.
- Движок оперирует типами сцен и идентификаторами. Держите сюжет, вопросы, реплики и награды в JSON, общие системные надписи в `strings.ts`, визуальные токены в `src/styles/`.
- Используйте добровольно предоставленные материалы для поздравления. Храните фотографии локально и добавляйте их с разрешения. Вымысел маркируйте в данных, а сомнительный факт оставляйте за пределами активных сцен.
- Сохраняйте доброжелательный тон, темп ведущего и положительный финал при любых ответах.
- После изменения запускайте `npm run validate:content`, `npm run typecheck`, `npm test` и `npm run build`. Для визуальных правок проверяйте 1920×1080 и 1366×768.
